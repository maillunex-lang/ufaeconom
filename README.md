# BUSINESS EMPIRE ONLINE

Экономическая MMO-стратегия для Android с 2.5D-изометрией. Разработка ведётся поэтапно.

## Прототип 0.1.0

Godot 4.3+, GDScript, GL Compatibility. Демонстрационная детерминированная карта 24×24 клеток, дороги, жилые дома, магазины, склады, заводы. Выбор участка, перемещение камеры пальцем/мышью, масштабирование жестом/колесом. Русский интерфейс.

### Запуск
Откройте `project.godot` в Godot 4.3+ и нажмите F6 на сцене `scenes/main.tscn` либо F5 для проекта.

### Ограничения
Это **локальный прототип**, а не работающая MMO. Реальная географическая база Башкортостана (54 района, по пять реальных названий поселений на район, плюс девять городских округов), сервер, компании, экономика, выборы, ИИ-игроки, Android APK и полноценные графические ассеты ещё не реализованы. Автоматическая проверка Godot и сборка APK пока не выполнялись.

### Дальнейшие модули
- `world`: справочники районов, seed-генерация, сохранение территорий.
- `economy`: компании, предприятия, товары, цены и сделки.
- `government`: бюджеты, выборы и полномочия.
- `agents`: ИИ-игроки с теми же правилами действий, что у людей.
- `network`: серверная авторитетная симуляция.

ИИ-игроки в будущем используют ограниченный игровой API и не могут напрямую изменять балансы, собственность или итоги выборов.
